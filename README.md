# SkillForge – Online Learning Platform

Fully functional multi-page website for an online courses / skill development marketplace.

## Features
- Responsive design, sticky header, mobile menu
- 600+ course detail pages with tabs, enroll buttons, curriculum
- Working cart (localStorage), quantity controls, checkout demo
- Category filtering, search, contact form, auth modal
- Blog, About, Categories, support pages
- All navigation and buttons work without errors

## How to run
Unzip and open `index.html` in a browser. Everything works offline.

## Domain
Online education / professional skill development – real-world useful application.
